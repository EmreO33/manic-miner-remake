# Manic Miner Remake

A modern browser remake of the 1983 ZX Spectrum classic Manic Miner (original by Matthew Smith). Single file, no build step: open `index.html`.

Caverns, art and code are original.

## Controls
- Move: Left/Right or A/D
- Jump: Space, Up or W
- P pause, M sound, C scanline filter
- Touch: on-screen buttons appear on first touch

Add `#dev` to the URL and press N to skip a level.
